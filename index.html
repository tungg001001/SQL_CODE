Lab 1: 基礎萬用密碼 (Auth Bypass)

目標： 輸入特定 SQL 語句破壞驗證邏輯，繞過密碼檢查成功登入 admin。

💡 觀念提示：使用單引號 ' 閉合原本的 SQL 語法欄位，並加上註解符號 -- 將後方的密碼比對邏輯忽略。
🔑 完整解法：在 Username 欄位輸入：admin' --，密碼可任意輸入即可成功繞過！

Lab 2: UNION 跨表資料擷取 (UNION Injection)

目標： 使用 UNION SELECT 跨表查詢，撈出隱藏在 secret_flags 資料表中的 Flag。

💡 觀念提示：確保 UNION 後方的欄位數量與前方的 id, username, role (3個欄位) 相同。
🔑 完整解法：使用 Payload：1 UNION SELECT 1, flag_value, 'flag_found' FROM secret_flags 來直接讀出 Flag。

Lab 3: 關鍵字黑名單繞過 (WAF Bypass)

目標： 後端設有 WAF 黑名單，過濾了小寫 union, select 與空格。請嘗試繞過過濾。

💡 觀念提示：可以使用 SQL 註解 /**/ 代替空格，或使用大小寫混淆來繞過簡單的字串比對。
🔑 完整解法：使用混合大小寫與註解代替空格的 Payload：UnIOn/**/SeLeCt。

Lab 4: 報錯注入 (Error-Based Injection)

目標： 系統會回傳詳細的資料庫錯誤訊息，請利用 SQL 爆錯將資料庫內的 Flag 隨錯誤訊息帶出。

💡 觀念提示：強制將字串類型的 flag_value 轉型為整數 (INT)，SQLite 轉型失敗時會將原始字串列在報錯訊息中。
🔑 完整解法：輸入：1 AND (SELECT CAST(flag_value AS INT) FROM secret_flags)，即可在 Error 中看到 Flag。

Lab 5: 布林盲注 (Boolean-Based Blind)

目標： 頁面不會顯示資料或報錯，只會回傳 exists: true/false。請盲猜出 Flag 內容。

💡 觀念提示：利用 SUBSTR(string, pos, length) 測試字元。若回傳 exists: true，代表猜對該位置的字母。
🔑 完整解法：輸入測試 Payload：admin' AND SUBSTR((SELECT flag_value FROM secret_flags), 1, 1) = 'F。

Lab 6: 時間盲注 (Time-Based Blind)

目標： 無論輸入什麼，頁面皆回傳固定狀態。請透過觸發伺服器回應延遲 (Delay) 進行判斷。

💡 觀念提示：觀察回應面板右側顯示的 Execution Time，若超過 2000ms 代表成功觸發延遲條件。
🔑 完整解法：輸入觸發延遲指令：1' AND DELAY --。

Lab 7: 二次注入 (Second-Order Injection)

目標： 第一步先寫入包含惡意語法的簡介；第二步呼叫觸發點，讓資料庫讀出該語法並二次執行。

💡 觀念提示：儲存時單引號會被正常存入資料庫，直到第二次 Query 被拼接到 Update 語句時才會爆發。
🔑 完整解法：在 Step 1 的 Bio 欄位儲存：guest' OR '1'='1，隨後點選按鈕 2 觸發。

Lab 8: 堆疊查詢 (Stacked Queries)

目標： 使用分號 ; 堆疊執行第二道 SQL 指令，對資料庫發動修改或破壞。

💡 觀念提示：分號允許在一筆 Request 中連續執行多條獨立的 SQL 語句 (如 UPDATE / INSERT)。
🔑 完整解法：輸入：UPDATE users SET role = 'admin' WHERE id = 2;。

Lab 9: 寬位元組轉義繞過 (Wide-Byte Bypass)

目標： 後端會強制將單引號轉義為 \'。請利用多位元組字元將斜線 \ 吃掉。

💡 觀念提示：%df 與 \ (%5c) 組合時會被解碼為一個繁體/寬位元組字元，從而還原單引號。
🔑 完整解法：輸入：%df' OR 1=1 --。

Lab 10: JSON 欄位注入 (JSON Injection)

目標： 現代 API 常接收 JSON 格式。請在 JSON 的屬性值中注入 SQL 語法。

💡 觀念提示：後端未對 JSON 提取出的 Value 做型態檢查便直接拼接到 SQL 語法中。
🔑 完整解法：輸入 JSON 內容：{"id": "1 OR 1=1"}。
